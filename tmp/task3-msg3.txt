docs(ultra): paste-ready operator note for the source-host probe upgrade

source-agent has no self-update and no artifact distribution, so the probe upgrade
cannot be deployed from here: the note is the deliverable that lets the host owner
install it in one sitting.

It carries the two files byte-for-byte in quoted heredocs, a timestamped backup
first, a drift gate over the documented deployed revision (a9cc8b87b1bebf8a370bda
023c9981ec, which the repo baseline reproduces exactly), the systemd restart, a
single command that verifies the new code is the code on disk and that the running
service started after it, how to read the first review's proof block on both the
source host and the panel, and the exact rollback.

Verified here: the embedded heredoc bodies hash to the same sha256 as the source
files after the note's own CRLF normalisation, both for an LF paste and for a
simulated Windows CRLF paste, and every shell block in the note passes bash -n.
