Bridge for iOS

Getting connected

Bridge signs in with a server address, a Client ID and an Agent Token. These are issued by the operator of the server you connect to — the app does not create accounts and does not sell access. If you run your own server, use the credentials that server's administrator gave you; if you were given access by someone else, ask them for the three values.

Common questions

The server says it does not trust this device. Check that the Client ID matches the one the Agent Token was issued for. A device identifier is derived from the Client ID, so a mismatched ID is refused.

The connection stops right after it starts. Open Tools → Tunnel logs and copy the last lines; they show which runtime stopped and why.

How do I remove my data? Sign out, delete the profile (this removes its Agent Token from the device), then uninstall the app. Records held on a server are deleted by that server's operator.
