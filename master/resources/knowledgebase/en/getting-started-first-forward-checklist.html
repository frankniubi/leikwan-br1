What you will accomplish

You will create one Forward from an active package, save only the visible destination settings, and record the assigned local port that your application will use.

Before you begin

  • Confirm that the package or service is Active.
  • Know the destination hostname or IP address.
  • Know the destination port.
  • Know whether the application needs TCP, UDP, or both.

The form asks only for the route package, destination, local port preference, and transport. Saving starts setup; the assigned local port is the value you need for the next guide.

  1. Open the active service and select Create Forward.
  2. Choose the offered package under Forward Route.
  3. Enter the destination in Target Host.
  4. Enter the service port in Target Port.
  5. Leave Local Listen Port blank to accept an assigned local port, unless you were given a specific safe port.
  6. Under Transport, choose TCP for TCP-only applications.
  7. Choose TCP + UDP when the application needs both.
  8. Choose UDP only for a UDP-only application.
  9. Select Create Forward to Save.
  10. Wait for provisioning to finish, then record the assigned local port shown on the Forward card.

How to know it worked

The new Forward appears with the destination and assigned local port you expect. A saved record is only the first checkpoint. Wait for active setup, then a recent client sync, and later confirm Running plus a successful application request.

If it did not work

Stop if no Forward Route is offered or the destination is uncertain. Do not guess at hidden settings. Check that the package is active, correct only the visible fields above, and ask your administrator to publish an appropriate route package when none is available.
