What you will accomplish

You will install the Client on Windows, Android, or Linux, sign in safely, and confirm that the device has received a recent configuration sync.

Before you begin

  • Have your panel Master URL, account Email, and Password ready for Windows.
  • For Android, use an arm64 device running Android 8.0+ and be ready to approve the VPN request.
  • For Linux, use a machine with systemd, Python 3, network access, and root-equivalent permission.
  • Treat credentials and copied commands as secrets. A Linux installer command contains a bearer agent token.

Each operating system has a different sign-in or installation path, but all three finish at the same observable result: the panel reports a recent client sync.

  1. Windows: Open Tenant → Clients and select Download Windows App.
  2. Install and open the app.
  3. Enter Master URL, Email, and Password.
  4. Select Connect.
  5. Confirm Connection successful!, the global state Connected, and each ready Forward marked Running.
  6. Android: Download and install the arm64 Android app on Android 8.0+.
  7. Sign in and approve the Android VPN request.
  8. Select one of the supported LeiGod services offered by the app. Use only a service that the app lets you select.
  9. Watch the visible state move from Ready to connect to Connecting... and then Connected.
  10. Linux: Open Tenant → Clients, expand Linux Install, and select Copy Install Command.
  11. Run the copied command once with root-equivalent permission. Do not paste it into chat, tickets, logs, or shared shell history.
  12. Confirm the installer prints installed leikwan-client-agent.
  13. Return to the panel and confirm a recent sync. On the Linux host, you may also confirm that config_pull_state.json reports status as ok.

How to know it worked

The panel shows a recent sync from the expected device. Windows also shows Connection successful!, global Connected, and a ready Forward as Running. Android reaches Connected. Linux reports the completed installer line and a successful pull state.

If it did not work

Stop before sharing credentials or rerunning secret commands in public places. Check the Master URL, device clock, internet access, required permissions, and the exact visible error. On Android, confirm the VPN approval was granted. On Linux, confirm systemd and Python 3 are available, then collect diagnostics without copying the bearer agent token.
