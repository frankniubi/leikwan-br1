The iPhone and iPad app is distributed through Apple's TestFlight, not the App Store. You request the invite once on the Clients page, then install and update the app from TestFlight.

What you will accomplish

The app installed from TestFlight, signed in with your Client ID and Agent Token, and connected.

Before you begin

  • An active package. The invite is only offered while a package is active.
  • An iPhone or iPad on iOS 16 or later.
  • The Apple ID that is signed in to the App Store on that device.
  • The TestFlight app, free from the App Store (published by Apple).

Steps

  1. Open the Clients page in the console and find the iOS · TestFlight card.
  2. Enter your Apple ID and click 申请 TestFlight 邀请 (request TestFlight invite). Each account records one Apple ID, so use the one on your device. After a few seconds the card shows 打开 TestFlight 邀请链接 (open the TestFlight invite link) and the server addresses for the app.
  3. Open the invite link on the iPhone or iPad. If you are on a computer, send the link to the device, for example in a message to yourself, and open it in Safari there. TestFlight opens the app's page: tap Accept, then Install.
  4. Open the app. On the home screen it is called Bridge the Fox Sake.
  5. Fill in the sign-in form. For Server address, tap Cloudflare CDN; on networks where it does not connect, use Directly CDN instead. The same two addresses are listed on the iOS card with copy buttons. Copy Client ID and Agent Token from the Clients page. The Client ID is the number shown there, not the Service ID of your package. Tap Save and sign in.
  6. Allow the VPN configuration when iOS asks the first time you connect, then tap Connect.

How to know it worked

The app shows Connected, and the iPhone or iPad appears in the online devices list at the bottom of the Clients page.

Keeping the app up to date

New versions arrive through TestFlight, not the App Store. On the app's page in TestFlight, turn on Automatic Updates, or open TestFlight and tap Update when a new build is listed. Each TestFlight build stops working 90 days after it is released; TestFlight warns you before that, and the newest build always installs from the same page.

If it did not work

  • The card says a valid package is needed. Buy or renew a package, then reload the Clients page.
  • The invite link opens a web page instead of TestFlight. Install TestFlight from the App Store first, then open the link again on the device.
  • TestFlight says the beta is full or no longer accepting testers. Contact support.
  • The Apple ID on the card is wrong. It cannot be changed in the console; contact support.
  • The app says the device is not trusted by the server. The Client ID is wrong, usually because the Service ID was entered. Sign out and sign in again with the Client ID from the Clients page.
  • Sign-in never finishes. Edit the profile and switch the server address to the other preset.
