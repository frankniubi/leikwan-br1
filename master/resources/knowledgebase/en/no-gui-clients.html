What you will accomplish

You will run the LeiKwan Bridge client on a Windows or macOS host that has no desktop session, register it so it starts by itself, and confirm that the machine's forwards are running and visible in the panel.

Before you begin

  • Have the panel Client ID and Agent Token for this machine ready; both are shown on the client card in Tenant → Clients.
  • macOS: install the app first (version 1.0.33 or newer), then run the installer with sudo.
  • Windows: download the no-GUI package and run the installer from an elevated PowerShell.
  • The windowless client is the same client as the desktop app: same tunnel, same lease handling, same runtime attestation. Only the interface is missing, so a machine never runs both at once.
  • Treat the Agent Token as a secret. The installer stores it in a root or SYSTEM owned file; never paste it into chat, tickets, or shared logs.

The diagram shows the only two decisions: which operating system the host runs, and whether the panel confirms the forwards afterwards.

  1. Pick the host. Use a machine that stays powered on; it needs no monitor, no signed-in desktop user, and no tray icon.
  2. macOS: install LeiKwan Bridge into /Applications from the current disk image.
  3. Download the LaunchDaemon installer (it registers com.leikwan.bridge.headless) and run it with the client identity: curl -fsSL https://v3.leikwanhost.com/artifacts/install-macos-headless.sh -o install-macos-headless.sh followed by sudo sh install-macos-headless.sh --panel https://v3.leikwanhost.com --client-id CLIENT_ID --agent-token AGENT_TOKEN.
  4. Windows: download leikwan-bridge-headless-win-x64.zip, extract it, and from an elevated PowerShell in that folder run .\install-windows-headless.ps1 -Panel https://v3.leikwanhost.com -ClientId CLIENT_ID -AgentToken AGENT_TOKEN.
  5. Confirm the registration. macOS: sudo sh install-macos-headless.sh --status. Windows: sc query LeikwanBridgeHeadless.
  6. Read the status file. macOS: /Library/Application Support/Leikwan/ClientAgent/headless-status.json. Windows: %ProgramData%\Leikwan\ClientAgent\headless-status.json.
  7. Confirm the document reports "Connected": true and every forward you expect reports "Running": true.
  8. Optional self check. Run the same program with the client identity plus --headless --once: it connects, waits, prints the same status document, and exits with code 0 when at least one forward is running.
  9. Day-to-day control uses the leikwan command the installer puts on your PATH: leikwan status shows the service state and every forward, leikwan logs -n 50 prints the client log, leikwan restart restarts it, and leikwan doctor checks the service, the status file, the log and the published version. macOS asks for your password because a LaunchDaemon runs as root; on Windows run the same commands from an elevated shell.
  10. Update with leikwan update: it reads the panel manifest, downloads the published build, verifies its SHA-256 against the manifest, replaces the payload and restarts the service. leikwan update --check only reports the installed and published versions and changes nothing.
  11. To remove it: macOS sudo sh uninstall-macos-headless.sh, Windows .\uninstall-windows-headless.ps1. Add --purge or -Purge to delete the stored token as well.

How to know it worked

leikwan status exits 0 when the client is connected with at least one running forward, so a monitoring script can call it directly. The service or daemon reports running, the status file reports "Connected": true with the expected forwards "Running": true, and the panel shows this machine online like any other client. The log next to the status file repeats the same state with timestamps. On macOS the daemon also restarts automatically at boot and after a crash; on Windows the service starts automatically and is configured to restart after a failure.

If it did not work

Stop before sharing the Agent Token or pasting installer commands into public places. Check the token and the client id first: a wrong token reports 401 Unauthorized in the log and never starts a forward. On macOS confirm that /Applications holds version 1.0.33 or newer and that the plist exists under /Library/LaunchDaemons. On Windows confirm the command ran elevated and that the token file is readable by SYSTEM. If the panel shows the machine online but a forward stays stopped, compare it with the panel before changing anything: the panel owns the forward list and the client re-applies it every few seconds.
