What you will accomplish

You will set up a computer that keeps your line running on its own — a server, a mini PC, or any machine that stays switched on. Nobody has to log in, and you will not see a window or an icon. You install it once, check that it works, and from then on you manage it with one short command.

Before you begin

  • Your Client ID and Agent Token from the panel's Clients page. They are the machine's login — treat them like a password.
  • Permission to install software on that machine (an administrator on Windows, your own password on macOS).
  • Two minutes. The download is about 80 MB on macOS and 34 MB on Windows.

The picture is the whole job: choose the system, run one command, then confirm. Everything after that happens in the background.

  1. Choose the computer. It should be one that stays on. It does not need a screen, a keyboard, or anyone logged in.
  2. Install the app first. On macOS, open the downloaded disk image and drag LeiKwan Bridge into Applications. On Windows, unpack the no-GUI download into a folder of your choice.
  3. Run the installer once. On macOS, open Terminal and paste the macOS command from the Clients page. On Windows, right-click the unpacked folder and choose Open in Terminal as administrator, then paste the Windows command. Both commands already contain this machine's identity.
  4. Check it started. Type leikwan status. You want to see the line listed as running.
  5. Look at the panel. The device appears online on the Clients page, exactly like a computer with the normal app.
  6. Later, three commands are all you need. leikwan status to check, leikwan restart if something looks stuck, and leikwan update to move to the newest version, and leikwan update --check if you only want to know whether an update exists.
  7. To remove it: run the uninstall command from the same Clients page, or leikwan stop to switch it off for now.

How to know it worked

Two simple checks. In the panel, this computer shows up as online, the same as any other device. On the computer itself, leikwan status prints the line as running — and it ends with a success code, so a monitoring tool can watch it for you. If you ever want the details, leikwan logs -n 50 shows the last 50 lines and leikwan doctor summarises the whole setup.

If it did not work

Stop and do not share your Agent Token with anyone — not in chat, tickets, or screenshots. The most common cause is a mistyped or expired Agent Token, which makes the panel show the device as offline while the log says the login was refused. Copy the Client ID and Agent Token again from the Clients page and run the installer command once more. If the device is online in the panel but a line still shows as stopped, wait half a minute — the panel decides which lines should run, and the computer follows within a few seconds. Still stuck? Send support the output of leikwan doctor, which contains no secrets.
