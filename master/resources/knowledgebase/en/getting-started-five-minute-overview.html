What you will accomplish

You will go from an active plan to a working line: add one forward in the panel, install the app, connect, and see the line running. About five minutes, and you never have to choose a connection type - every line uses ultra, which keeps the route steady while you play.

Before you begin

  • An active plan, so the panel lets you create a forward.
  • The game or program you want to speed up, and the address it connects to (the game's server list usually shows it).
  • Windows, Android, or Linux on the device you play on. A phone works as well as a computer.
  • Your panel login, and about five minutes.

Five steps, each one covered in a few lines below. Nothing here needs a technical decision.

  1. Open the panel and check the plan is active. Latest package on the Overview page shows its status; if it is expired or suspended, you cannot create a forward.
  2. Create a forward. Open My Services and click New forward on your package. Pick the line closest to the game's server, type the address and port the game connects to, keep the suggested local port, and save. Note that local port down - the game needs it in step 5.
  3. Install the app on the device you play on: Windows, macOS or Android from the Clients page, or the one-line Linux command. Sign in with your panel account.
  4. Connect. The app lists your forward; press connect and wait until it reads running.
  5. Point the game at the client. Wherever the game asks for a server address, use 127.0.0.1 and the local port from step 2, then start the game.
  6. Play, and glance at the panel afterwards. The forward's Usage this cycle goes up while you play.

How to know it worked

Three signs, in this order: the app shows the line as running, the forward in the panel shows incoming traffic while you play, and the game itself stays steady instead of spiking in the middle of a match. If the game starts but the traffic numbers stay at zero, the local port is almost always the reason - check step 5 again.

If it did not work

Stop and check the plan first if the panel refuses to save the forward: an expired plan is the most common reason on day one. The next most common is the wrong destination - use the address the game really connects to, not the address of the site you downloaded it from. Third is the local port: the game has to use exactly the port the panel assigned. Everything else - the app will not stay connected, the line keeps dropping, the game cannot reach the server - is covered in the troubleshooting guide below.
