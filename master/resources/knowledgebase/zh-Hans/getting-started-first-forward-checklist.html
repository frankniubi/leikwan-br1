一条转发就是你在面板上画的一条线：你的游戏或服务在哪里，以及本机用哪个端口去连它。

你将完成什么

一条保存好的转发，加上一个分配给你的本地端口。下一条指南要用这个端口，先记下来。

开始前准备

  • 一个有效套餐，面板才允许保存转发。
  • 你的游戏或服务真正监听的地址和端口。
  • 它需要哪种传输方式：TCP、UDP 还是两者都要。游戏一般是 UDP。

操作步骤

  1. 打开 Forwards，点 Create Forward。
  2. 选择 Forward Route。挑离目标最近的那条线路。所有线路都用 ultra，这里不需要再决定别的。
  3. 填写 Target Host 和 Target Port。这里要填游戏自己连的地址，不是你下载游戏的网站地址。
  4. 选择 Transport，也就是你的服务需要的传输方式：TCP、UDP 或 TCP + UDP。
  5. 保存。Local Listen Port 用默认建议值就行，除非你有特别的理由要改。
  6. 记下分配给你的本地端口。几秒后它会显示在这一行上。

表单只问线路、目标、传输方式和本地端口，其余都替你填好了。

如何确认成功

这一行会稳定停在已保存状态，而不是反复显示预配中，并且本地端口已经填好。接着去 Clients 页面，能看到准备承载这条转发的设备有最近同步时间。

如果没有成功

面板不让保存时，先停止，别反复点。三个常见原因：套餐已经失效；目标地址或端口填错；你填的本地端口已经被占用——清空它，让面板重新分配一个。
