在你玩游戏的那台设备上装一次客户端，登录之后让它一直开着就行。以后只要偶尔看一眼线路还在不在。

你将完成什么

客户端装好、用面板账号登录，并且在面板里显示为在线。

开始前准备

  • 你的面板邮箱和密码。
  • 你玩游戏用的设备。客户端支持 Windows、Android 和 Linux。
  • 手机或平板需要 Android 8.0 以上。
  • Linux 需要 64 位 ARM（arm64）机器，并且能执行一条 root 命令。

操作步骤

  1. 打开 Clients 页面。需要的东西都在这一页。
  2. 安装客户端。Windows 点 Download Windows App；手机装 arm64 安装包；Linux 点 Copy Install Command，再执行这条命令。
  3. 登录。用面板的邮箱和密码。进去之后客户端会显示 Connection successful!。
  4. 让它一直开着。客户端显示 Connected，开关显示 Running。

三种设备最后都停在同一处：客户端已经登录，面板里能看到它最近同步过。

如何确认成功

看两处。客户端显示 Connected，Clients 页面里这台设备有最近同步时间。

如果没有成功

如果一直停在 Connecting...，先停止，重新登录一次。按可能性排：密码不对，或者账号还没生效；Android 把客户端在后台休眠了；Linux 命令没有用 root 执行。
