在你玩游戏的那台设备上装一次客户端，登录之后让它一直开着就行。以后只要偶尔看一眼线路还在不在。

你将完成什么

客户端装好、用控制台账号登录，并且在控制台「客户端」页面的「在线设备」里能看到它。

开始前准备

  • 你的控制台邮箱和密码。
  • 你玩游戏用的设备。客户端支持 Windows、macOS、Android 和 Linux。
  • 手机或平板需要 Android 8.0 以上。
  • Linux 需要 Debian 11、12 或 13（x86_64 或 arm64 都可以），并且能用 root 执行命令。

操作步骤

  1. 打开「客户端」页面。需要的东西都在「下载与安装」这一块里。
  2. 安装客户端。Windows 点「下载安装包」；Android 点「下载 APK」；macOS 点对应芯片的下载按钮；Linux 点「复制命令」，再在目标机器上执行这条命令。
  3. 登录。用控制台的邮箱和密码。进去之后客户端会显示 Connection successful!。
  4. 让它一直开着。客户端显示 Connected，开关显示 Running。

几种设备最后都停在同一处：客户端已经登录，控制台的「在线设备」里能看到它。

如何确认成功

看两处。客户端显示 Connected；「客户端」页面底部的「在线设备」里出现这台设备（IP、系统和客户端版本）。

如果没有成功

如果一直停在 Connecting...，先停止，重新登录一次。按可能性排：密码不对，或者账号还没生效；同时在线的设备已经达到套餐上限（看页面上的「最大在线」）；Android 把客户端在后台休眠了；Linux 命令没有用 root 执行。
