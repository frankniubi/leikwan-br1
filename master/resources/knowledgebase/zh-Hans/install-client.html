你将完成什么

你将在 Windows、Android 或 Linux 上安装并登录客户端，随后确认设备在线且已经收到最近的转发配置。

开始前准备

  • Windows 登录需要面板提供的 Master URL、Email 和 Password。
  • Android 需要 arm64、Android 8.0+ 设备，并允许系统建立 VPN 连接。
  • Linux 主机需要 systemd、Python 3、网络访问能力和相当于 root 的权限。
  • 登录信息和复制的命令都属于秘密；Linux 安装命令包含可直接用于代理身份验证的令牌。

三个平台的安装入口和状态名称不同，但结束条件一致：目标设备上的客户端已连接，并且面板显示最近同步。

  1. Windows：打开 Tenant → Clients，选择 Download Windows App。
  2. 安装并打开应用，填写 Master URL、Email 和 Password。
  3. 选择 Connect，确认出现 Connection successful!，全局状态为 Connected，可用转发显示 Running。
  4. Android：在 arm64、Android 8.0+ 设备上安装应用并登录。
  5. 同意 Android 的 VPN 授权，只选择应用列出的受支持 LeiGod 服务。
  6. 观察状态从 Ready to connect 经过 Connecting... 变为 Connected。不要据此承诺 Android 支持 Race 或 MPTCP。
  7. Linux：打开 Tenant → Clients，展开 Linux Install，选择 Copy Install Command。
  8. 以相当于 root 的权限运行一次复制的命令；不要把它粘贴到聊天、工单、日志或共享历史记录。
  9. 确认安装器输出 installed leikwan-client-agent。
  10. 回到面板查看最近同步；也可在主机上确认 config_pull_state.json 的 status 为 ok。

如何确认成功

面板应显示预期客户端的最近同步。Windows 同时显示 Connection successful!、Connected 和转发的 Running；Android 到达 Connected；Linux 安装完成且拉取状态正常。之后仍需单独验证真实应用连接。

如果没有成功

先停止公开凭据或反复运行秘密命令。核对 Master URL、设备时间、网络和权限。Android 要确认 VPN 授权；Linux 要确认 systemd 与 Python 3 可用。收集错误时删除代理身份验证令牌等秘密内容。
