你将完成什么

你将从已生效的套餐或服务出发，创建一条转发，安装并登录客户端，再用真实应用协议完成首次连接验证。保存配置只是起点，最终目标是应用收到预期响应。

开始前准备

  • 确认套餐或服务状态为有效。
  • 准备目标主机、目标端口，以及应用所需的 TCP、UDP 或两者。
  • 准备一台支持的 Windows、Android 或 Linux 设备。
  • 不要向任何人展示密码、令牌、复制的安装命令、密钥、会话或线路材料。

最短且安全的路径只有一次判断：真实应用请求通过本地监听端口并获得正确结果，就算完成；否则先保留现有转发，再从可见症状着手排查。

  1. 在租户面板中打开已生效的服务。
  2. 选择 Create Forward。
  3. 选择系统提供的线路方案，并填写目标地址和端口。
  4. 保存转发，记下系统分配的本地端口。
  5. 安装客户端并登录。
  6. 等待客户端出现最近同步记录。
  7. 让应用连接本地监听地址和端口。
  8. 使用实际应用协议验证，例如发出 HTTP 请求、建立 SSH 连接或启动游戏连接。

如何确认成功

保存后已完成配置记录，预配完成后端点可用，最近同步表示配置已送达，Connected 或 Running 表示运行状态正常；这些检查点彼此独立。最终证据仍是应用请求成功，并在可查看时由目标日志确认请求到达。

如果没有成功

先停止随意更改线路或端口。保留第一条转发，记录错误内容和发生时间，再按排查指南逐项检查。不要把保存、预配、最近同步、运行连接和应用成功混为一谈。
