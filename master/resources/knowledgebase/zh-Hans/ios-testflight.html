iPhone 和 iPad 版通过苹果的 TestFlight 分发，不在 App Store 上架。在控制台「客户端」页面申请一次邀请，之后安装和更新都在 TestFlight 里完成。

你将完成什么

从 TestFlight 装好 App，用客户端 ID 和 Agent Token 登录，并且连上。

开始前准备

  • 一个有效套餐。只有套餐有效时才能申请邀请。
  • iOS 16 或以上的 iPhone 或 iPad。
  • 这台设备上登录 App Store 用的 Apple ID。
  • App Store 里的 TestFlight（苹果官方出品，免费）。

操作步骤

  1. 打开「客户端」页面，找到 iOS · TestFlight 这一块。
  2. 填写 Apple ID，点「申请 TestFlight 邀请」。每个账户只记录一个 Apple ID，请填这台设备上用的那个。几秒后卡片会出现「打开 TestFlight 邀请链接」按钮，以及 App 要填的服务器地址。
  3. 在 iPhone 或 iPad 上打开邀请链接。如果你是在电脑上操作，先把链接发到手机上（比如发给自己的一条消息），再用手机上的 Safari 打开。TestFlight 会打开 App 页面：点「接受」，再点「安装」。
  4. 打开 App。桌面上的名字是 Bridge the Fox Sake。
  5. 填写登录信息。「服务器地址」点 Cloudflare CDN；如果当前网络连不上，改点 Directly CDN。这两个地址在 iOS 卡片上也列出来了，可以直接复制。「客户端 ID」和 Agent Token 从「客户端」页面复制。客户端 ID 是那里显示的数字，不是套餐的服务编号（Service ID）。最后点「保存并登录」。
  6. 允许添加 VPN 配置。第一次连接时 iOS 会弹窗询问，点「允许」，然后点「连接」。

如何确认成功

App 显示已连接，并且「客户端」页面底部的「在线设备」里出现这台 iPhone 或 iPad。

如何更新

新版本通过 TestFlight 推送，不走 App Store。在 TestFlight 的 App 页面里打开「自动更新」，或者看到新版本时打开 TestFlight 点「更新」。每个 TestFlight 版本发布 90 天后会失效，到期前 TestFlight 会提醒，从同一个页面装最新版即可。

如果没有成功

  • 卡片提示需要有效套餐。购买或续费套餐后刷新「客户端」页面。
  • 邀请链接打开的是网页而不是 TestFlight。先从 App Store 安装 TestFlight，再在设备上重新打开链接。
  • TestFlight 提示测试名额已满或不再接受测试员。请联系客服。
  • 卡片上的 Apple ID 填错了。控制台里不能自己改，请联系客服。
  • App 提示「此设备未被服务器信任」。客户端 ID 填错了，通常是填成了服务编号。退出登录，用「客户端」页面上的客户端 ID 重新登录。
  • 一直登录不上。编辑配置，把服务器地址换成另一个预设。
