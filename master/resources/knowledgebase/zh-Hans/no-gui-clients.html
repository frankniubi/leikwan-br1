你将完成什么

你会在没有桌面会话的 Windows 或 macOS 主机上运行 LeiKwan Bridge 客户端，让它开机自启，并确认这台机器的转发已经在运行且面板可见。

开始前准备

  • 准备好这台机器对应的面板 Client ID 与 Agent Token，它们显示在 租户 → 客户端 的客户端卡片上。
  • macOS：先安装应用（1.0.33 或更新版本），再用 sudo 运行安装脚本。
  • Windows：下载无界面版压缩包，并以管理员身份打开 PowerShell 运行安装脚本。
  • 无界面版与图形客户端是同一个客户端：同一条隧道、同一套租约处理、同一份运行时指纹，只是没有界面，因此同一台机器不要同时运行两者。
  • Agent Token 属于机密。安装脚本会把它写进仅 root 或 SYSTEM 可读的文件；不要粘贴到聊天、工单或共享日志里。

这张图只包含两个判断：主机运行哪个系统，以及面板随后是否确认转发已经运行。

  1. 选择主机。用一台长期开机的机器，不需要显示器、不需要登录桌面用户、也不会有托盘图标。
  2. macOS：从当前磁盘映像把 LeiKwan Bridge 安装到 /Applications。
  3. 下载 LaunchDaemon 安装脚本（它会注册 com.leikwan.bridge.headless）并带上客户端身份运行：先执行 curl -fsSL https://v3.leikwanhost.com/artifacts/install-macos-headless.sh -o install-macos-headless.sh，再执行 sudo sh install-macos-headless.sh --panel https://v3.leikwanhost.com --client-id CLIENT_ID --agent-token AGENT_TOKEN。
  4. Windows：下载 leikwan-bridge-headless-win-x64.zip 并解压，在该目录以管理员身份运行 .\install-windows-headless.ps1 -Panel https://v3.leikwanhost.com -ClientId CLIENT_ID -AgentToken AGENT_TOKEN。
  5. 确认已注册。macOS 执行 sudo sh install-macos-headless.sh --status；Windows 执行 sc query LeikwanBridgeHeadless。
  6. 查看状态文件。macOS 为 /Library/Application Support/Leikwan/ClientAgent/headless-status.json；Windows 为 %ProgramData%\Leikwan\ClientAgent\headless-status.json。
  7. 确认文件里 "Connected": true，并且你期望的每条转发都是 "Running": true。
  8. 可选自检。用同一个程序和同一客户端身份再加上 --headless --once 运行：它会连接、等待、打印同一份状态文档，并在至少一条转发运行时以退出码 0 结束。
  9. 需要卸载时：macOS 执行 sudo sh uninstall-macos-headless.sh，Windows 执行 .\uninstall-windows-headless.ps1；加上 --purge 或 -Purge 可一并删除已保存的令牌。

如何确认成功

服务或守护进程显示为 running，状态文件里 "Connected": true 且期望的转发为 "Running": true，面板中这台机器与其他客户端一样在线。状态文件旁边的日志会带时间戳重复同样的状态。macOS 的守护进程在开机与崩溃后都会自动重启；Windows 服务设为自动启动，并配置了失败后自动重启。

如果没有成功

先停止对外分享 Agent Token，也不要把安装命令粘贴到公开位置。先核对令牌与 Client ID：令牌错误时日志会显示 401 Unauthorized，并且不会启动任何转发。macOS 请确认 /Applications 里的应用是 1.0.33 或更新版本，且 plist 已写入 /Library/LaunchDaemons。Windows 请确认是在管理员权限下执行，且令牌文件对 SYSTEM 可读。如果面板显示机器在线但某条转发仍处于停止状态，先与面板上的状态对照再动手：转发列表以面板为准，客户端每隔几秒就会重新应用一次。
