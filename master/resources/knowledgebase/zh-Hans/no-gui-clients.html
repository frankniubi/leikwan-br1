你将完成什么

你会让一台电脑自己把线路跑起来 —— 一台服务器、一台小主机，或者任何长期开机的机器。没有人需要登录，桌面上不会出现窗口或图标。装一次、确认一次，之后用一条短命令管理它。

开始前准备

  • 控制台「客户端」页面上的 客户端 ID 和 客户端令牌，它们就是这台机器的登录凭据，请像密码一样保管。
  • 在这台机器上安装软件的权限（Windows 需要管理员，macOS 需要你自己的密码）。
  • 两分钟时间。macOS 下载约 80 MB，Windows 约 34 MB。

整件事就是这张图：选系统、运行一条命令、确认结果。之后的一切都在后台进行。

  1. 挑选电脑。用一台长期开机的机器，不需要显示器、不需要键盘，也不需要有人登录。
  2. 先安装应用。macOS：打开下载的磁盘映像，把 LeiKwan Bridge 拖进 应用程序。Windows：把无界面版下载包解压到一个文件夹。
  3. 运行一次安装命令。macOS：打开「终端」，粘贴客户端页面「无界面版」里「复制 macOS 命令」得到的命令。Windows：在解压出来的文件夹上右键，以管理员身份打开终端，粘贴「复制 Windows 命令」得到的命令。两条命令里都已经带了这台机器的身份。
  4. 确认已经启动。输入 leikwan status，看到转发显示为 running 就对了。
  5. 回到控制台看一眼。这台设备会像装了普通客户端的电脑一样出现在「在线设备」里。
  6. 以后只需要三条命令。查看用 leikwan status，觉得卡住用 leikwan restart，升级用 leikwan update；如果只想看看有没有新版本，用 leikwan update --check。
  7. 需要卸载时：运行同一个客户端页面上的卸载命令，或者先用 leikwan stop 暂时关掉它。

如何确认成功

两个简单检查。控制台「在线设备」里能看到这台电脑，和其他设备一样；在电脑上运行 leikwan status，线路显示为 running，并且命令以成功状态结束，所以监控工具也可以直接用它。想看细节时，leikwan logs -n 50 显示最近 50 行日志，leikwan doctor 一次列清整体状态。

如果没有成功

先停止把客户端令牌发给任何人 —— 聊天、工单、截图都不行。最常见的原因是客户端令牌抄错或已失效：控制台里看不到这台设备在线，日志里会写着登录被拒绝。回到客户端页面重新复制客户端 ID 与客户端令牌，再运行一次安装命令即可。如果控制台显示设备在线、但某条转发仍是停止状态，等半分钟 —— 转发由控制台决定，电脑会在几秒内跟上。仍然不通，就把 leikwan doctor 的输出发给客服，那份内容不含任何机密。
