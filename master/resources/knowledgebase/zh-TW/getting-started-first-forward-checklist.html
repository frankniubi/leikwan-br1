一條轉發就是你在面板上畫的一條線：你的遊戲或服務在哪裡，以及本機用哪個連接埠去連它。

你將完成什麼

一條儲存好的轉發，加上一個分配給你的本機連接埠。下一條指南要用這個連接埠，先記下來。

開始前準備

  • 一個有效方案，面板才允許儲存轉發。
  • 你的遊戲或服務真正監聽的位址和連接埠。
  • 它需要哪種傳輸方式：TCP、UDP 還是兩者都要。遊戲一般是 UDP。

操作步驟

  1. 打開 Forwards，點 Create Forward。
  2. 選擇 Forward Route。挑離目標最近的那條線路。所有線路都用 ultra，這裡不需要再決定別的。
  3. 填寫 Target Host 和 Target Port。這裡要填遊戲自己連的位址，不是你下載遊戲的網站位址。
  4. 選擇 Transport，也就是你的服務需要的傳輸方式：TCP、UDP 或 TCP + UDP。
  5. 儲存。Local Listen Port 用預設建議值就好，除非你有特別的理由要改。
  6. 記下分配給你的本機連接埠。幾秒後它會顯示在這一列上。

如何確認成功

這一列會穩定停在已儲存狀態，而不是反覆顯示佈建中，並且本機連接埠已經填好。接著去 Clients 頁面，能看到準備承載這條轉發的裝置有最近同步時間。

如果沒有成功

面板不讓儲存時，請先停止，別反覆點。三個常見原因：方案已經失效；目標位址或連接埠填錯；你填的本機連接埠已經被佔用——清空它，讓面板重新分配一個。
