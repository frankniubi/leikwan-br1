你將完成什麼

你會從有效方案建立一條轉發，只填寫畫面上看得到的目標設定，並記下應用程式之後要使用的本機連接埠。

開始前準備

  • 確認方案或服務狀態為有效。
  • 準備目標服務的主機名稱或 IP 位址。
  • 準備目標服務使用的連接埠。
  • 確認應用程式需要 TCP、UDP，或兩者都需要。

操作步驟

表單只需要線路方案、目標、偏好的本地連接埠和傳輸方式。儲存後會開始佈建；下一篇指南真正需要的是分配的本機連接埠。

  1. 開啟有效服務，選擇建立轉發。
  2. 在 Forward Route（轉發路由）選擇面板提供的線路方案。
  3. 在 Target Host（目標主機）填入目標位址。
  4. 在 Target Port（目標連接埠）填入服務連接埠。
  5. 除非已取得特定且安全的連接埠，否則將 Local Listen Port（本地監聽連接埠）留空，接受系統分配。
  6. 在 Transport（傳輸）選擇 TCP，供只使用 TCP 的應用程式使用。
  7. 應用程式同時需要兩種協定時，選擇 TCP + UDP。
  8. 只有完全使用 UDP 的應用程式才選擇 UDP。
  9. 選擇 Create Forward（建立轉發）以儲存。
  10. 等待佈建完成，再從轉發卡片記下系統分配的本機連接埠。

如何確認成功

新的轉發會顯示預期的目標和本機連接埠。資料已儲存只是第一個檢查點；接著要等設定啟用、用戶端最近同步，最後看到 Running 且應用程式成功收到回應。

如果沒有成功

請先停止操作，特別是沒有可選的轉發路由，或目標資訊不確定時。不要猜測隱藏設定。先確認方案有效，只修正上述可見欄位；若沒有合適線路，請管理員發布可用的方案。
