你將完成什麼

你會在沒有桌面工作階段的 Windows 或 macOS 主機上執行 LeiKwan Bridge 用戶端，讓它開機自動啟動，並確認這台機器的轉發已在運作且面板可見。

開始前準備

  • 準備好這台機器對應的面板 Client ID 與 Agent Token，它們顯示在 租戶 → 用戶端 的用戶端卡片上。
  • macOS：先安裝應用程式（1.0.33 或更新版本），再以 sudo 執行安裝腳本。
  • Windows：下載無介面版壓縮檔，並以系統管理員身分開啟 PowerShell 執行安裝腳本。
  • 無介面版與圖形用戶端是同一個用戶端：同一條通道、同一套租約處理、同一份執行時指紋，只是沒有介面，因此同一台機器不要同時執行兩者。
  • Agent Token 屬於機密。安裝腳本會將它寫入僅 root 或 SYSTEM 可讀的檔案；不要貼到聊天、工單或共享日誌中。

這張圖只有兩個判斷：主機執行哪個系統，以及面板隨後是否確認轉發已經運作。

  1. 選擇主機。使用一台長期開機的機器，不需要螢幕、不需要登入桌面使用者、也不會有系統匣圖示。
  2. macOS：從目前的磁碟映像將 LeiKwan Bridge 安裝到 /Applications。
  3. 下載 LaunchDaemon 安裝腳本（它會註冊 com.leikwan.bridge.headless）並帶上用戶端身份執行：先執行 curl -fsSL https://v3.leikwanhost.com/artifacts/install-macos-headless.sh -o install-macos-headless.sh，再執行 sudo sh install-macos-headless.sh --panel https://v3.leikwanhost.com --client-id CLIENT_ID --agent-token AGENT_TOKEN。
  4. Windows：下載 leikwan-bridge-headless-win-x64.zip 並解壓縮，在該目錄以系統管理員身分執行 .\install-windows-headless.ps1 -Panel https://v3.leikwanhost.com -ClientId CLIENT_ID -AgentToken AGENT_TOKEN。
  5. 確認已註冊。macOS 執行 sudo sh install-macos-headless.sh --status；Windows 執行 sc query LeikwanBridgeHeadless。
  6. 查看狀態檔。macOS 為 /Library/Application Support/Leikwan/ClientAgent/headless-status.json；Windows 為 %ProgramData%\Leikwan\ClientAgent\headless-status.json。
  7. 確認檔案中 "Connected": true，且你預期的每條轉發都是 "Running": true。
  8. 選用自我檢查。用同一個程式與同一用戶端身份再加上 --headless --once 執行：它會連線、等待、印出同一份狀態文件，並在至少一條轉發運作時以退出碼 0 結束。
  9. 需要移除時：macOS 執行 sudo sh uninstall-macos-headless.sh，Windows 執行 .\uninstall-windows-headless.ps1；加上 --purge 或 -Purge 可一併刪除已儲存的權杖。

如何確認成功

服務或守護程序顯示為 running，狀態檔中 "Connected": true 且預期的轉發為 "Running": true，面板中這台機器與其他用戶端一樣在線。狀態檔旁邊的日誌會帶時間戳重複同樣的狀態。macOS 的守護程序在開機與崩潰後都會自動重啟；Windows 服務設為自動啟動，並設定失敗後自動重啟。

如果沒有成功

請先停止對外分享 Agent Token，也不要將安裝指令貼到公開位置。先核對權杖與 Client ID：權杖錯誤時日誌會顯示 401 Unauthorized，且不會啟動任何轉發。macOS 請確認 /Applications 中的應用程式為 1.0.33 或更新版本，且 plist 已寫入 /Library/LaunchDaemons。Windows 請確認是在系統管理員權限下執行，且權杖檔案對 SYSTEM 可讀。若面板顯示機器在線但某條轉發仍為停止狀態，先與面板上的狀態對照再處理：轉發清單以面板為準，用戶端每隔幾秒就會重新套用一次。
