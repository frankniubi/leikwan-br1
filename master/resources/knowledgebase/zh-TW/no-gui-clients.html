你將完成什麼

你會讓一台電腦自己把線路跑起來 —— 一台伺服器、一台小主機，或任何長期開機的機器。沒有人需要登入，桌面上不會出現視窗或圖示。裝一次、確認一次，之後用一條短指令管理它。

開始前準備

  • 面板「用戶端」頁面上的 Client ID 與 Agent Token，它們就是這台機器的登入憑證，請像密碼一樣保管。
  • 在這台機器上安裝軟體的權限（Windows 需要系統管理員，macOS 需要你自己的密碼）。
  • 兩分鐘時間。macOS 下載約 80 MB，Windows 約 34 MB。

整件事就是這張圖：選系統、執行一條指令、確認結果。之後的一切都在背景進行。

  1. 挑選電腦。用一台長期開機的機器，不需要螢幕、不需要鍵盤，也不需要有人登入。
  2. 先安裝應用程式。macOS：打開下載的磁碟映像，把 LeiKwan Bridge 拖進 應用程式。Windows：把無介面版下載包解壓縮到一個資料夾。
  3. 執行一次安裝指令。macOS：打開「終端機」，貼上用戶端頁面上的 macOS 指令。Windows：在解壓縮出來的資料夾上按右鍵，以系統管理員身分開啟終端機，貼上頁面上的 Windows 指令。兩條指令裡都已經帶了這台機器的身份。
  4. 確認已經啟動。輸入 leikwan status，看到轉發顯示為 running 就對了。
  5. 回到面板看一眼。這台裝置會像裝了普通用戶端的電腦一樣顯示在線。
  6. 之後只需要三條指令。查看用 leikwan status，覺得卡住用 leikwan restart，升級用 leikwan update；如果只想看看有沒有新版本，用 leikwan update --check。
  7. 需要移除時：執行同一個用戶端頁面上的移除指令，或先用 leikwan stop 暫時關掉它。

如何確認成功

兩個簡單檢查。面板裡這台電腦顯示在線，和其他裝置一樣；在電腦上執行 leikwan status，線路顯示為 running，而且指令以成功狀態結束，所以監控工具也可以直接用它。想看細節時，leikwan logs -n 50 顯示最近 50 行日誌，leikwan doctor 一次列清整體狀態。

如果沒有成功

請先停止把 Agent Token 發給任何人 —— 聊天、工單、截圖都不行。最常見的原因是 Agent Token 抄錯或已失效：面板會顯示裝置離線，日誌裡會寫著登入被拒絕。回到用戶端頁面重新複製 Client ID 與 Agent Token，再執行一次安裝指令即可。如果面板顯示裝置在線、但某條轉發仍是停止狀態，等半分鐘 —— 轉發由面板決定，電腦會在幾秒內跟上。仍然不通，就把 leikwan doctor 的輸出傳給客服，那份內容不含任何機密。
