你將完成什麼

你會讓一臺電腦自己把線路跑起來 —— 一臺伺服器、一臺小主機，或者任何長期開機的機器。沒有人需要登入，桌面上不會出現視窗或圖示。裝一次、確認一次，之後用一條短命令管理它。

開始前準備

  • 控制台「用戶端」頁面上的 用戶端 ID 和 用戶端令牌，它們就是這臺機器的登入憑據，請像密碼一樣保管。
  • 在這臺機器上安裝軟體的許可權（Windows 需要管理員，macOS 需要你自己的密碼）。
  • 兩分鐘時間。macOS 下載約 80 MB，Windows 約 34 MB。

整件事就是這張圖：選系統、執行一條命令、確認結果。之後的一切都在後臺進行。

  1. 挑選電腦。用一臺長期開機的機器，不需要顯示器、不需要鍵盤，也不需要有人登入。
  2. 先安裝應用。macOS：開啟下載的磁碟映像，把 LeiKwan Bridge 拖進 應用程式。Windows：把無介面版下載包解壓到一個資料夾。
  3. 執行一次安裝命令。macOS：開啟「終端」，貼上用戶端頁面「無介面版」裡「複製 macOS 命令」得到的命令。Windows：在解壓出來的資料夾上右鍵，以管理員身份開啟終端，貼上「複製 Windows 命令」得到的命令。兩條命令裡都已經帶了這臺機器的身份。
  4. 確認已經啟動。輸入 leikwan status，看到轉發顯示為 running 就對了。
  5. 回到控制台看一眼。這臺裝置會像裝了普通用戶端的電腦一樣出現在「線上裝置」裡。
  6. 以後只需要三條命令。檢視用 leikwan status，覺得卡住用 leikwan restart，升級用 leikwan update；如果只想看看有沒有新版本，用 leikwan update --check。
  7. 需要解除安裝時：執行同一個用戶端頁面上的解除安裝命令，或者先用 leikwan stop 暫時關掉它。

如何確認成功

兩個簡單檢查。控制台「線上裝置」裡能看到這臺電腦，和其他裝置一樣；在電腦上執行 leikwan status，線路顯示為 running，並且命令以成功狀態結束，所以監控工具也可以直接用它。想看細節時，leikwan logs -n 50 顯示最近 50 行日誌，leikwan doctor 一次列清整體狀態。

如果沒有成功

先停止把用戶端令牌發給任何人 —— 聊天、工單、截圖都不行。最常見的原因是用戶端令牌抄錯或已失效：控制台裡看不到這臺裝置線上，日誌裡會寫著登入被拒絕。回到用戶端頁面重新複製用戶端 ID 與用戶端令牌，再執行一次安裝命令即可。如果控制台顯示裝置線上、但某條轉發仍是停止狀態，等半分鐘 —— 轉發由控制台決定，電腦會在幾秒內跟上。仍然不通，就把 leikwan doctor 的輸出發給客服，那份內容不含任何機密。
