你將完成什麼

你會在 Windows、Android 或 Linux 上安裝並登入用戶端，接著確認裝置已在線，並收到最近的轉發設定。

開始前準備

  • Windows 登入需要 App 顯示的 Master URL、Email 和 Password。
  • Android 需要 arm64、Android 8.0+ 裝置，並準備允許系統建立 VPN 連線。
  • Linux 主機需要 systemd、Python 3、可用的網路，以及等同 root 的權限。
  • 登入資訊和複製的指令都屬於機密；Linux 安裝指令內含用於 Agent 身分驗證權杖。

三個平台的安裝入口和畫面狀態不同，但完成條件一致：目標裝置上的用戶端已連線，面板也顯示最近同步。

  1. Windows：開啟 Tenant → Clients → Install（租戶 → 線路 → Install），選擇 Download Windows App（下載 Windows App）。
  2. 安裝並開啟 App，填入 Master URL、Email 和 Password。
  3. 選擇 Connect，確認出現 Connection successful!，整體狀態為 Connected，可用轉發顯示 Running。
  4. Android：在 arm64、Android 8.0+ 裝置安裝 App 並登入。
  5. 允許 Android 的 VPN 要求，只選擇 App 列出的支援的 LeiGod 服務。
  6. 觀察狀態從 Ready to connect，經過 Connecting...，最後成為 Connected。不能因此承諾 Android 支援 Race 或 MPTCP。
  7. Linux：開啟 Tenant → Clients → Install（租戶 → 線路 → Install），展開 Linux Install（Linux 安裝），選擇 Copy Install Command（複製安裝指令）。
  8. 以等同 root 的權限執行一次複製的指令；不要貼到聊天、工單、記錄或共用的 Shell 歷程。
  9. 確認安裝程式輸出 installed leikwan-client-agent。
  10. 回到面板查看最近同步；也可在主機確認 config_pull_state.json 的 status 為 ok。

如何確認成功

面板會顯示預期用戶端的最近同步。Windows 也會出現 Connection successful!、整體 Connected 和轉發 Running；Android 到達 Connected；Linux 則完成安裝並成功拉取設定。之後仍要另外驗證真實應用程式連線。

如果沒有成功

請先停止公開登入資料或重複執行含機密的指令。核對 Master URL、裝置時間、網路和必要權限。Android 要確認已允許 VPN；Linux 要確認 systemd 與 Python 3 可用。收集診斷時，請移除 Agent 身分驗證權杖等機密內容。
