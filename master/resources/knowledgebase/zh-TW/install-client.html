在你玩遊戲的那臺裝置上裝一次用戶端，登入之後讓它一直開著就行。以後只要偶爾看一眼線路還在不在。

你將完成什麼

用戶端裝好、用控制台帳號登入，並且在控制台「用戶端」頁面的「線上裝置」裡能看到它。

開始前準備

  • 你的控制台郵箱和密碼。
  • 你玩遊戲用的裝置。用戶端支援 Windows、macOS、Android 和 Linux。
  • 手機或平板需要 Android 8.0 以上。
  • Linux 需要 Debian 11、12 或 13（x86_64 或 arm64 都可以），並且能用 root 執行命令。

操作步驟

  1. 開啟「用戶端」頁面。需要的東西都在「下載與安裝」這一塊裡。
  2. 安裝用戶端。Windows 點「下載安裝包」；Android 點「下載 APK」；macOS 點對應晶片的下載按鈕；Linux 點「複製命令」，再在目標機器上執行這條命令。
  3. 登入。用控制台的郵箱和密碼。進去之後用戶端會顯示 Connection successful!。
  4. 讓它一直開著。用戶端顯示 Connected，開關顯示 Running。

如何確認成功

看兩處。用戶端顯示 Connected；「用戶端」頁面底部的「線上裝置」裡出現這臺裝置（IP、系統和用戶端版本）。

如果沒有成功

如果一直停在 Connecting...，先停止，重新登入一次。按可能性排：密碼不對，或者帳號還沒生效；同時線上的裝置已經達到套餐上限（看頁面上的「最大線上」）；Android 把用戶端在後臺休眠了；Linux 命令沒有用 root 執行。

相關指南

接著做連線並驗證。裝好還沒有轉發，先看建立第一條轉發。有問題可以看排查常見問題；沒有螢幕的機器看無介面執行用戶端。
