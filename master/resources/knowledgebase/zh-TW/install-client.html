在你玩遊戲的那台裝置上裝一次用戶端，登入之後讓它一直開著就好。之後只要偶爾看一眼線路還在不在。

你將完成什麼

用戶端裝好、用面板帳號登入，並且在面板裡顯示為在線。

開始前準備

  • 你的面板電子郵件和密碼。
  • 你玩遊戲用的裝置。用戶端支援 Windows、Android 和 Linux。
  • 手機或平板需要 Android 8.0 以上。
  • Linux 需要 64 位元 ARM（arm64）機器，並且能執行一條 root 指令。

操作步驟

  1. 打開 Clients 頁面。需要的東西都在這一頁。
  2. 安裝用戶端。Windows 點 Download Windows App；手機裝 arm64 安裝包；Linux 點 Copy Install Command，再執行這條指令。
  3. 登入。用面板的電子郵件和密碼。進去之後用戶端會顯示 Connection successful!。
  4. 讓它一直開著。用戶端顯示 Connected，開關顯示 Running。

如何確認成功

看兩處。用戶端顯示 Connected，Clients 頁面裡這台裝置有最近同步時間。

如果沒有成功

如果一直停在 Connecting...，請先停止，重新登入一次。依可能性排：密碼不對，或者帳號還沒生效；Android 把用戶端在背景休眠了；Linux 指令沒有用 root 執行。

相關指南

接著做連線並驗證。裝好還沒有轉發，先看建立第一條轉發。有問題可以看排查常見問題；沒有螢幕的機器看無介面執行用戶端。
