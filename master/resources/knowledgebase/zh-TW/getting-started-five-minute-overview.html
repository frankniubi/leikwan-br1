你將完成什麼

你會從有效方案開始，完成一條轉發，安裝用戶端，並用真實應用程式確認首次連線。重點不只是把設定儲存起來，而是透過系統分配的本機連接埠送出要求，收到預期回應。

開始前準備

  • 確認方案或服務標示為有效。
  • 準備目標位址、目標連接埠，以及應用程式使用 TCP、UDP 或兩者的資訊。
  • 準備一台支援的 Windows、Android 或 Linux 裝置安裝用戶端。
  • 不要分享密碼、權杖、複製的安裝指令、私密金鑰或線路資料。

最短且安全的流程只有一個判斷點：應用程式要求成功，就代表首次設定完成；若失敗，保留已儲存的轉發，從看得見的症狀開始排查。

  1. 在租戶面板開啟有效服務。
  2. 選擇建立轉發。
  3. 選擇面板提供的線路方案，填入目標位址和連接埠。
  4. 儲存轉發，記下系統分配的本機連接埠。
  5. 安裝用戶端並登入。
  6. 等待面板出現最近同步。
  7. 讓應用程式連到本機監聽位址與連接埠。
  8. 使用實際應用協定測試，例如 HTTP 要求、SSH 連線或遊戲連線。

如何確認成功

佈建完成後，面板會顯示有效端點，用戶端有最近同步，轉發則顯示 Connected 或 Running。這些是不同階段的狀態；完整證明仍是應用程式要求成功並取得預期結果。若你管理目標服務，也應能在記錄中看到要求抵達。

如果沒有成功

請先停止隨意調整線路細節。保留第一條轉發，記下確切錯誤和時間，再開啟排查指南。設定已儲存、佈建完成、最近同步、程序執行中，以及應用程式成功，是五個不同的檢查點。
