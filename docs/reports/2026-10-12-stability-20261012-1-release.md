## Runtime changes since 2026.10.11.2

- **Ack-based write stall.** The relay write-progress bound is 5 s and counts only bytes the peer acknowledged (SIOCOUTQ on Linux/Android, SO_NWRITE on macOS). A relay that stops reading is left within about 6 s.
- **Status writes off the failover path.** `StatusWriter` used to write and fsync the status file inline on whichever goroutine called it. Callers include the HA dial path between candidate attempts and the policy watcher, so a slow disk stalled them for up to a second. This was the Windows CI timeouts. Writes now happen on a timer goroutine. Snapshots are taken under `writeMu`, so they can never land out of order, and `Close` waits for a write in flight.
- **macOS UoT unsent cap.** macOS honours `TCP_NOTSENT_LOWAT` only for writability, so a slowing carrier hid seconds of datagrams in the kernel and the lag detector never fired. That meant 26% loss and no failover, reproduced 3/3 on GitHub arm64 and on the Frankfurt Intel Mac. The writer now holds batches back while `TCP_CONNECTION_INFO` shows more than 128 KiB unsent. On the Intel Mac, failover now happens with 0.1% loss (3/3), and the full darwin suite passes.
- **UDP queue default is 1024 everywhere** (agent, desktop hosts, runtime).

## Other changes

- **Linux agent.** `_apply_forward_locked` compared the new runtime config with what it had just written, so an auxiliary-runtime change never restarted it. It now compares against the previous content.
- **Android.** The APK no longer ships wstunnel, which scanners flag as "ELF:WSTunnel-A [PUP]". Ultra does not use it. Legacy single mode and bond-fallback ingress now fail with their existing "requires packaged wstunnel" error.
- **CI gate fixes.**
  - The .NET concurrency test proves overlap instead of timing it.
  - The window capture expects at most the visible screen; the arm64 runner's display is smaller than 1440x900.
  - The canary leak fixture waits up to 10 minutes and prints why it failed.
  - The test status writers are closed before their TempDir is removed.
  - The lag-test relay sizes its receive buffer on the listener.
  - The frozen-agent job no longer dies of SIGPIPE.
