## What changed
- Navigation: Dashboard, Services and nodes, Connect, Native outbound (only while the plan assigns one), Log, Settings. The Nodes item is gone; its old view name now opens the services page.
- Services and nodes: cloud sync, import and the node list sit above the per-service pairing rows, on one page. The duplicate pairing list on the old Nodes page is removed.
- Connect: the connection settings are no longer folded into an expander. The page starts with the optional-connection note (zh and en).
- Native outbound: its own page. It shows only while `NativeOutboundForwards` is non-empty, which is the same condition the old card used.
- Dashboard: four account cards (plan, usage, rate limit, home province) above the existing forward control list.
  - Plan: no data source in the client yet. Shows "not provided" (`DashPlanUnavailable`).
  - Usage: this session's traffic counters, with the existing ring gauge.
  - Rate limit: summary of the line `speed_limit_mbps` values: unlimited, one shared value, or "varies by line".
  - Home province: read from `GET /api/client/access/policy` (`main_province_code`), at most every 10 minutes, once after connecting. Read-only. Unknown or unread shows "not loaded".
