## What changed

- **Android VPN dropping on its own.** An Ultra renewal that returned a different relay set rebuilt the whole VpnService. A renewal now injects the new leases in place, or restarts only the Ultra runtime on the same port. Reopening the app no longer stops a running native tunnel.
- **Android app redesign.**
  - Three tabs and a FlClash-style dashboard.
  - One Material 3 palette in day and night variants.
  - Fewer words on screen.
  - The sign-in screen takes a client ID and token only, and offers theme and language before sign-in.
  - In-app update check and download. Downloads are same-origin, verified against sha256 and size, and handed to the system installer. The version number is shown in Settings.
- **Per-app routing (Android).** Two layers: the VPN scope (include or exclude packages) and per-app policy rules. Presets cover streaming, AI, Google and music apps.
- **The user's own nodes in the cloud.** Shadowsocks, SOCKS5 and VLESS, keyed by client, 32 per client.
  - Two-way sync: device to cloud and cloud to device.
  - Nodes can be edited in the tenant console ("My Nodes").
  - Pairing with forwards is automatic or manual; manual wins.
  - A node can be removed from this device only.
  - The UI says "Your own node"; protocols are named only where a node is added.
- **Desktop.** FlClash-style UI and cloud node sync on Windows and macOS (Apple silicon only). Forward listeners stay on 0.0.0.0 / [::]; that is intended.
- **Panel.** Hosted-node endpoints and the `client_hosted_nodes` table (migration `20261012_add_client_hosted_nodes`, applied 07:26:40 UTC).
- **WHMCS billing error (`whmcs_response_error`).** The WHMCS API allowlist (`tblconfiguration.APIAllowedIPs`, last edited 2026-10-10 15:52 UTC) did not include the live panel IP, so every panel-to-WHMCS call got "Invalid IP 117.55.193.164". This broke billing sync, LeiKwan Buy sign-in, balance transfer and binding tickets.
  - The IP has been added. Backup: `/root/codex-backups/whmcs-api-allowlist-20261012/`.
  - Commit `a4a761e6` logs WHMCS's refusal reason server-side and shows a readable message to tenants.
