## Change

- **Native outbound rules never ask for a node.** A native outbound forward leaves through the panel's own exit, so it no longer appears in the Services list with a node picker. The native outbound card lists every native rule directly as a selectable row. Services and native rules share one selection: picking one clears the other. The card's old on/off switch and carrier dropdown are gone; its expand arrow holds the scope and policy settings for the picked rule.
- The panel's per-forward `native_outbound` flag is now parsed (the same flag Windows uses), alongside the native capability's carrier list.
- A stale selection on a native rule falls back to the first ordinary service, so an ordinary connect never pairs a node with a native rule. App group lines exclude native rules.
