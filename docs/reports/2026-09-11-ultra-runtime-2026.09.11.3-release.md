## 2026.09.11.4 UDP 性能补丁(dd02ca77 / 18c4ecf3)

- 现场证据：jstc 内核 `UdpRcvbufErrors=75,407`(自开机累计)——OS 默认数据报接收缓冲在突发时溢出，内核静默丢包。
- 修复：本地与上行 UDP socket 全部 `SetReadBuffer/SetWriteBuffer(4MB)`；runtime 响应通道 32→512；pending 队列默认 64→256(三平台 host 配置同步)；删除 100k association 硬拆除(每 10 万包固定丢 1 包 + 全量重建握手)；idle GC 2min→10min。
- 五个平台 runtime 重建为 `2026.09.11.4.dd02ca77` 并发布面板(备份 `/root/codex-backups/ultra-runtime-20260911-4`)，双入口 canary 通过，`windows_client_app.runtime_sha256` 已指向新哈希以便桌面端 drift 自更新。
- jstc 客户端：发布后主机网络抖动、SSH 间歇不可达；恢复后 Agent 已自动把 runtime 升级为 `2026.09.11.4.dd02ca77`。随后计划重启 158/159/170/171/180(新 PID 2163689–2163702)，全部 ready；forward-170 canary TCP 402B/1.128s、UDP 71B/0.05s 通过。`UdpRcvbufErrors` 基线 75,407(旧内核缓冲溢出累计)，11.4 起本地/上行 socket 均为 4MB 缓冲，需观察计数器不再增长。
