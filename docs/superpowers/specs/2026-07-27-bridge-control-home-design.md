# Bridge Control Home

## Direction

Turn the public home page into an operational entry point for LeiKwan Bridge.
The visual language is a light paper workbench with dark ink, coral action
color, and restrained status colors. The page should feel like a control plane,
not a promotional landing page.

## First viewport

- Compact brand and session navigation.
- Chinese-first title with the product name and `Bridge Control` descriptor.
- One primary console action and one anchor to the network path section.
- A framed control-plane status block with live setup state.
- The beginning of the network section visible below the fold.

## Information hierarchy

1. Product identity and immediate console entry.
2. Truthful runtime counts: active nodes, regions, edge endpoints, and admins.
3. The supported path: client -> slave -> sidecar -> target.
4. Short operating principle and links to console and knowledgebase.

## Constraints

- Scope the new skin to the home page only.
- Keep existing authentication, registration, knowledgebase, and dashboard
  templates on their current public skin.
- Do not add client-selection claims or invented runtime data.
- Avoid gradients, canvas animation, decorative blobs, nested cards, and
  viewport-scaled typography.
- Keep all controls keyboard-focusable and responsive at mobile widths.
