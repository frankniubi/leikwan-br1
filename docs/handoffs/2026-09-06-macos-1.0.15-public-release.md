# macOS 1.0.15 release

## Release scope

The user confirmed the 1.0.15 test build works and requested synchronization and
new installer packages on 2026-09-06. Promote the tested binaries without another
client rebuild. The release replaces only the two Mac DMGs, two update ZIPs, and
their four entries in `artifacts/versions.json`. No PHP or other platform payload
changes are included.
